C# Comments

What Are Comments?

When you code something and you want someone to understand what does it do and you don't want to explain it yourself. Use comments. comments are notes in your code that are ignored by the compiler. they are crucial especially when you work with people and you want then to know the context of you code to avoid confusion.

Single-Line Comments

Single line comments start with two forward slashes (//) and extend to the end of the line.

// This is a single-line comment

Multi-Line Comments

Unlike single-line comments, multi-line comments can span multiple lines and are enclosed between /* and */. better used if you need to comment out large sections of code.

/* This is a
   multi-line comment */
