C# Type Casting and User Input

What Is Type Casting?

Type Casting is the process of forcibly converting a value from one data type to another. and there are two types of castign we will be learning today.

Implicit Casting

Implicit casting is when you convert a value from a smaller data type to a larger data type without losing information. this is more safe since no lost of data will occur.

int myInt = 9;
double myDouble = myInt;
Console.WriteLine(myInt);
Console.WriteLine(myDouble);

Output:

9
9

Explicit Casting

Explicit casting is when you convert a value from a larger data type to a smaller data type, which may result in a loss of information.

double price = 9.78;
int whole = (int)price;
Console.WriteLine(whole);

Output:

9

Type Conversion

Type conversion is the process of converting a value from one data type to another using built-in methods. 

string text = "25";
int age = Convert.ToInt32(text);
Console.WriteLine(age + 1);

Output:

26

What Is User Input?

User input refers to the data that a user provides to a program during its execution. In C#, you can read user input using methods like Console.ReadLine() which we will also learn today.

Reading Text

Console.ReadLine() is used to read a line of text from the user. but always REMEMBER that the value returned by Console.ReadLine() is a string, so you may need to convert it to another data type if necessary.

Console.Write("Enter your name: ");
string name = Console.ReadLine();
Console.WriteLine("Hello, " + name);

Output (if the user types Alex):

Enter your name: Alex
Hello, Alex

Reading Numbers

As I said earlier, the value returned by Console.ReadLine() is a string, so you need to convert it to a numeric type if you want to perform mathematical operations.

Console.Write("Enter your age: ");
int age = Convert.ToInt32(Console.ReadLine());
Console.WriteLine("Next year you will be " + (age + 1));

Output (if the user types 20):

Enter your age: 20
Next year you will be 21
