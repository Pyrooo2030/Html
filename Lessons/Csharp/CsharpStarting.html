C# Getting Started and Printing

Where To Start Coding

1

Open Your IDE

Donwload the visual studio installer from https://visualstudio.microsoft.com/vs/community/ and after download choose the .NET Desktop Development. then click install

2

Create A New Project

To create a new C# console project, open Visual Studio and select "Create a new project". Choose "Console App" and click "Next".

3

Find Where To Type

The code file is usually named `Program.cs` and is located in the project folder. to start typing your code, simply click on the Text editor area and start typing.

4

Write And Run Your First Line with WriteLine() and Write()

There are two main methods for printing in C#: Console.WriteLine() and Console.Write(). The difference is that Console.WriteLine() adds a newline character at the end, while Console.Write() does not. also remember that Csharp runs code Sequentially, meaning it runs the code from top to botton. meaning placement of code can give different results.

// This will print "Hi, World!" followed by a newline
Console.WriteLine("Hi, World!");
// This will print "Hi, World!" without a newline
Console.Write("Hi, World!");

Output:

Hi, World! 
Hi, World!

What Is Printing?

So what you experienced earlier was the concept of printing output to the console terminal. known as printing, this is a fundamental way to display information to the user. its mainly used to display results of operations or to provide feedback to the user.

How To Print

As stated earlier, the two main methods for printing in C# are Console.WriteLine() and Console.Write().

Try It Yourself

Since now you know the basics of printing in C#, try creating a simple program that uses both Console.WriteLine() and Console.Write() to see the difference in their output.

EXTRA: try using Console.Write() then put Console.WriteLine() below it to see what would it look like.
