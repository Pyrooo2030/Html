C# Variables, Constants, and Data Types

What Are Variables?

When thinking how one can input a value into a program or a coding language, they think where to put it. That's where the variable steps in. Think of a variable as a container that holds a value. Its main purpose is to store and use as a storage for either user input (we'll talk about this later) or a fixed value.

Creating A Variable

To create a variable we need 3 things: The Data Type, the Name, and the Value.

DataType VariableName = Value;
string name = "Your name";

Printing A Variable

To print the value of a variable, you can use the Console.WriteLine() method that we learned last time.

int age = 20;
Console.WriteLine(age);

Output:

20

Changing A Variable

You can change the value of a variable at any time during the execution of your program.

int age = 20;
age = 21;
Console.WriteLine(age);

Output:

21

Constants

Constant are variables whose value cannot be changed once a value is assigned to them. imagine it as a locked box that you can only put something in once. its syntax is always const before the data type.

const int maxLives = 3;
Console.WriteLine(maxLives);

Output:

3
